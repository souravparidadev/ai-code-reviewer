# AI Code Reviewer

An event-driven AI code review system that listens to GitHub pull request events, analyzes changed code with LLMs, and posts automated review comments.

## Stack
- Node.js / Express
- TypeScript
- PostgreSQL
- Redis
- Docker
- GitHub OAuth + Webhooks
- OpenAI / Claude
- Pinecone
- React dashboard
